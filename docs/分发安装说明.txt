Codex 账号切换台 0.4.6 / Codex Account Switcher 0.4.6

当前 0.4.6 为测试候选，尚未通过完整发布验收。以 v0.4.6-rc.1 预发布形式分发。
This candidate is distributed as the v0.4.6-rc.1 pre-release. Full real-account switching acceptance is incomplete.

前一候选 0.4.6-local.1 核验了 Codex 26.1021.31345 (21828)、内置后端 0.164.0-alpha.11.1，兼容新版内嵌 CodexCLI.app 及旧版布局。本版沿用该兼容逻辑，旧结果不视为新验收。后续 OpenAI 官方签名版本在满足最低版本、file 凭据后端及运行时协议检查时可自动兼容。
The preceding 0.4.6-local.1 candidate was checked with Codex 26.1021.31345 (21828) and backend 0.164.0-alpha.11.1, including the new nested CodexCLI.app and older layouts. This build retains that compatibility logic; prior results are not new acceptance. Later OpenAI-signed versions can run when the minimum-version, file-storage, and runtime protocol checks pass.

中文安装步骤
1. 从项目 v0.4.6-rc.1 Release 下载 ZIP 与 SHA256SUMS，校验文件完整性。
2. 将 App 拖到“应用程序”。升级前先退出旧切换台，保留账号库。
3. 本包为 ad-hoc 本地签名，未经 Apple 公证。首次打开如被拦截，在“系统设置 → 隐私与安全性”中为该 App 选择“仍要打开”。不要全局关闭 Gatekeeper。
4. App 显示在菜单栏。系统密码仅输入 macOS 系统窗口；后台不会主动要求密码。
5. 新构建可能需要再次允许打开或显式钥匙串授权。完整说明见 App 中“更多设置 → 说明”。

English installation
1. Download the ZIP and SHA256SUMS from the v0.4.6-rc.1 project Release and verify integrity.
2. Move the App to Applications. Quit the old switcher before upgrading; the account library is retained.
3. This build is ad-hoc signed and not Apple-notarized. If the first launch is blocked, allow this specific app via System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally.
4. The app runs in the menu bar. Enter passwords only in macOS system dialogs. Background operations do not request passwords.
5. A new build may need another first-launch exception or explicit Keychain authorization. Read More settings → 说明 for the full guide.

账号列表会完整显示登录邮箱，邮箱只保存在本机账号元数据中，不包含在脱敏诊断、公开源码或分发成品中。
The account list displays full login emails, stored only in local account metadata and excluded from sanitized diagnostics, public source, and distribution artifacts.

换号前先保存工作并退出共享认证的 CLI / IDE。确认“退出并切换”后，工具先验证目标，再请求正常退出、写入凭据和重开 Codex；不会强杀进程。启动成功仍需在 Codex 中核对实际账号和工作区。额度栏显示剩余量和服务端重置时间；后台同步只更新已保存的当前账号。Google 和 Apple 登录按同一账号身份规则处理。
Save work and quit shared-auth CLI / IDE processes before switching. After explicit confirmation, the target is validated before normal termination, credential replacement, and reopen; processes are not force-killed. Reopening still requires verification of the actual account and workspace in Codex. Usage shows the remaining allowance and server reset time; background credential synchronization updates only the already-saved current account. Google and Apple login use the same identity rules.
