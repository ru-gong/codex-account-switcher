Codex 账号切换台 0.4.4 / Codex Account Switcher 0.4.4

此为预发布候选，完整实机验收尚未完成。This is a pre-release candidate; full real-world acceptance is incomplete.

支持 macOS 14+、Apple Silicon，Codex 26.911.61220 (9647)，内置后端 0.155.0-alpha.2.6；同时支持 26.908.70816 (9275)、26.908.40834 (8881)、26.903.71938 (8576)、26.903.61454 (8378)。
Supports macOS 14+, Apple Silicon, and the pinned Codex version above.

中文安装步骤
1. 从项目 GitHub Releases 获取 ZIP 与 SHA256SUMS，校验文件完整性。
2. 将 App 拖到“应用程序”。升级前先退出旧切换台，保留账号库。
3. 本包为 ad-hoc 本地签名，未经 Apple 公证。首次打开如被拦截，在“系统设置 → 隐私与安全性”中为该 App 选择“仍要打开”。不要全局关闭 Gatekeeper。
4. App 显示在菜单栏。系统密码仅输入 macOS 系统窗口；后台不会主动要求密码。
5. 新构建可能需要再次允许打开或显式钥匙串授权。完整说明见 App 中“更多设置 → 说明”。

English installation
1. Download the ZIP and SHA256SUMS from the project's GitHub Releases and verify integrity.
2. Move the App to Applications. Quit the old switcher before upgrading; the account library is retained.
3. This build is ad-hoc signed and not Apple-notarized. If the first launch is blocked, allow this specific app via System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally.
4. The app runs in the menu bar. Enter passwords only in macOS system dialogs. Background operations do not request passwords.
5. A new build may need another first-launch exception or explicit Keychain authorization. Read More settings → 说明 for the full guide.
